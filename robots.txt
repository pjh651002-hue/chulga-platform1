# 대한불교조계종 출가 안내
#
# 색인 여부는 index.html 의 <meta name="robots"> 로 제어합니다.
# 지금은 시제품이라 그 값이 noindex 입니다.
#
# 여기서 Disallow 로 수집을 막지 않는 이유:
# 수집을 막으면 검색엔진이 noindex 표시를 읽지 못해, 설명 없는 주소만
# 검색 결과에 남을 수 있습니다. 수집을 허용해야 색인에서 확실히 빠집니다.
#
# 정식 공개 시에는 index.html 의 robots 값을 "index, follow" 로 바꾸면 되고,
# 이 파일은 그대로 두셔도 됩니다.

User-agent: *
Allow: /

Sitemap: https://chulga-platform1.vercel.app/sitemap.xml
